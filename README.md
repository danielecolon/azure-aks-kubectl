# AKS and kubectl: Create Your Cluster and Take Command

![AKS and kubectl](aks-kubectl.avif)

## Details
Ready to explore Kubernetes on Azure? Join us for an online session covering how to set up Azure Kubernetes Service (AKS), connect to your cluster, and use kubectl to deploy and manage applications.

We’ll begin with the fundamentals, explain how AKS and Kubernetes fit together, and walk through practical demonstrations.

What we’ll cover:
- Creating an AKS cluster using Azure CLI
- Configuring cluster access and understanding authentication and permissions
- Using kubectl to explore nodes, namespaces, Pods, and Services
- Deploying an application with a Kubernetes YAML manifest
- Scaling workloads, viewing logs, and troubleshooting common problems
- Recovering from a failed deployment and cleaning up Azure resources
- Whether you’re new to Azure, familiar with Azure but new to Kubernetes, or looking to build confidence with AKS and kubectl, this session will give you a practical starting point.

No prior Kubernetes experience is required. You can follow the demonstrations without an Azure subscription. We’ll finish with time for questions and discussion.
